# Cryptography Learnings

Welcome to the **Cryptography Learnings** repository! This collection showcases various cryptographic algorithms and techniques implemented in Java, aimed at providing hands-on experience and a deeper understanding of classical and modern encryption methods.

## 📚 Overview

This repository contains Java implementations of several cryptographic algorithms, including:

- **Classical Ciphers**: Affine Cipher, Caesar Cipher, Vigenère Cipher, Playfair Cipher, Hill Cipher, Autokey Cipher, Transposition Cipher.
- **Modern Ciphers**: Data Encryption Standard (DES), Advanced Encryption Standard (AES), Simplified Data Encryption Standard (SDES).
- **Cryptographic Attacks**: Affine Cipher Attack, Caesar Cipher Attack, Hill Cipher Attack.
- **Mathematical Foundations**: Prime Number Algorithms, Modular Arithmetic, Extended Euclidean Algorithm, Fermat's Little Theorem, Chinese Remainder Theorem.

These implementations serve as educational examples to demonstrate the inner workings of cryptographic systems.

## 🧪 Features

- **Educational Implementations**: Clear, commented Java code to understand the algorithms.
- **Cryptographic Attacks**: Demonstrations of how certain ciphers can be broken.
- **Mathematical Algorithms**: Implementations of foundational number-theoretic concepts used in cryptography.
- **Client-Server Models**: Examples of how cryptographic algorithms can be applied in secure communication scenarios.
